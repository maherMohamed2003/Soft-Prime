KEY FEATURES

What the system does

Bulk Order Import

Import hundreds of orders at once from an Excel batch file.

Rep Assignment

Assign unassigned orders to reps in bulk with live search and filters.

Collection Tracking

See what each rep collected, owes, or still needs to hand over.

Daily Performance View

Delivery rate, order count and dues per rep for any selected day.

Order Status & Notes

Update status and notes per order directly from the list, instantly saved.

Supplier & Merchant Records

Every order linked to its merchant office and shipping fee.
