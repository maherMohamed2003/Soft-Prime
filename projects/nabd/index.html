Nabd — Offline Pharmacy Management

← All Projects

Nabd is a fully offline-first pharmacy system — everything runs and saves inside the browser itself, no server or internet connection required. It tracks medicine batches by expiry, sells with automatic FEFO deduction, and calculates real net profit after cost and expenses.

KEY FEATURES

What the system does

Offline-First — No Server Needed

Everything saves inside the browser itself — the pharmacy keeps working even with no internet at all.

Batch & Expiry Tracking

Every medicine can have multiple batches, each with its own quantity, cost and expiry date.

Automatic FEFO Deduction

Sales automatically deduct from the batch closest to expiry first, cutting expired-stock losses.

Real Net Profit Reports

Net profit calculated as sales minus real medicine cost minus expenses, with margin percentage.

Low-Stock & Expiry Alerts

Dashboard badges and tables flag low-stock items and medicines nearing expiry automatically.

JSON Backup & Restore

Download all data as one JSON file and restore it on any device — solving the offline-only limitation.
